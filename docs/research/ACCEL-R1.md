# ACCEL-R1 — permissive driver references for SDM845 / OnePlus 6

Research checked **2026-10-24 PT** by web search and direct source inspection. Each linked path is evidence for its own row; line counts are **physical file lines** measured 2026-10-24 (`wc -l` or source viewer), not semantic code LOC. Source date means inspection date unless a publication date is stated. `UNKNOWN` means no verified implementation, license, line count, or SDM845 match for that cell. A generic host-controller driver is not evidence that its Qualcomm glue, PHY, clocks, firmware, or OnePlus board path works. [Redox's driver guide](https://github.com/redox-os/drivers/blob/master/README.md), checked 2026-10-24, explicitly recommends studying BSD drivers while rewriting monolithic driver logic for Redox userspace schemes.

**License boundary.** The main table accepts BSD-2-Clause, BSD-3-Clause, MIT, and Apache-2.0 (including MIT/Apache dual license). OpenBSD's inspected Qualcomm files carry **ISC-style** grants: permissive, but outside the user's literal BSD/MIT/Apache list, so they are recorded separately and not silently relabeled BSD. A file in a mostly permissive repository is **not** automatically reusable; use its exact header. Linux GPL sources and Qualcomm EFI binaries are design/compatibility evidence only. [OpenBSD source files](https://github.com/openbsd/src/tree/master/sys/dev/fdt), [U-Boot source files](https://github.com/u-boot/u-boot/tree/master/drivers), and [Redox driver guidance](https://github.com/redox-os/drivers/blob/master/README.md) checked 2026-10-24.
